✅ Final Institute Lists (Cleaned & Deduplicated)

Deduplicated, institution-level files prepared from collected sources. These represent the canonical foundation for the national census.

Source: Final Institute Lists/
Category File Name Institutions States / UTs Districts Academic Year Official ID Duplicate IDs Missing Fields Quality Status Review
Distinction between Source Datasets & Final Institute Lists:
A Source Dataset contains raw program-level or board-level entries (e.g., 5,108 nursing programmes or 11,585 medical courses).
A Final Institute List has been algorithmically parsed, deduplicated, and unified so that each row represents a single physical institution with its respective regulatory codes and addresses.

🛡️ Data Quality & Integrity Scorecard

Automated validation metrics covering null values, duplicate checks, official ID integrity, and geographic completeness.

Dataset / List Total Rows Unique Records Duplicate IDs Missing Names Missing State Missing District Missing Address Missing PIN Status

PASS Criteria

100% Institution Names present, valid Official Regulator IDs, 0 duplicate keys, and complete State mapping.

WARNING Criteria

Minor missing attributes such as PIN codes or addresses in older institutions, or partial state tagging (e.g. overseas institutes).

NEEDS REVIEW Criteria

Large volume datasets with withheld names/codes in research export (e.g., UDISE+ DSP pseudocodes requiring KYS track mapping).
